# Управление складом (учебная конфигурация 1С:Предприятие 8)

Учебный проект складского учёта на платформе 1С:Предприятие 8.

## Что умеет конфигурация

- Справочники **Номенклатура** (артикул, цена) и **Склады**.
- Документ **ПоступлениеТоваров**: шапка со складом, табличная часть с товарами, количеством и ценой. При проведении создаёт движения прихода.
- Документ **РасходТоваров**: движения расхода. Перед проведением проверяет остатки по каждому товару с учётом суммы по документу и запрещает проведение при нехватке.
- Проверка заполнения документов:
  - дата в диапазоне от месяца назад до месяца вперёд;
  - заполнен склад;
  - есть хотя бы одна строка товаров;
  - в строках заполнены номенклатура и количество, количество больше нуля;
  - в поступлении цена больше нуля.
- Управляемая форма документа:
  - проверка выполняется до записи, при ошибке проведение отменяется, текст выводится в окно сообщений;
  - проблемное поле или ячейка таблицы подсвечивается розовым через условное оформление;
  - подсветка снимается при изменении поля и при следующей проверке;
  - стандартная кнопка «Провести» использует обработчик `ПередЗаписью` формы.
- Регистр накопления **ТоварыНаСкладах** (вид «Остатки», измерения: номенклатура и склад, ресурс: количество).
- Общие модули:
  - **УправлениеОстатками**: функция `ПолучитьОстатки` возвращает остатки списка товаров по складу одним запросом;
  - **УправлениеДвижениями**: процедура `ЗаписатьДвиженияТоваров` записывает движения по строкам документа;
  - **ПроверкаДанныхДокументов**: функции проверки даты, склада, табличной части, строк и цены, а также `ОшибкаЗаполненияСтруктура`, которая возвращает структуру с текстом, именем поля и номером строки.
- Отчёт **ОстаткиТоваров** на основе схемы компоновки данных (СКД): остатки по номенклатуре и складу.
- Подсистема **СкладскойУчет**.

## Известные ограничения

- Курсор не ставится на строку таблицы с ошибкой: подсвечиваются только ячейки.
- Подсветка ячейки таблицы и поля шапки выглядит немного по-разному из-за отрисовки таблицы.
- Проверка дат при проведении задним числом по закрытым периодам не сделана.
- Сообщения выводятся через `Сообщить`, без `СообщитьПользователю` (в учебной конфигурации нет БСП).
