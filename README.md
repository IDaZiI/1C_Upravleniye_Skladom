# Управление складом (учебная конфигурация 1С:Предприятие 8)

Учебный проект складского учёта на платформе 1С:Предприятие 8.

## Что умеет конфигурация

- Справочники **Номенклатура** (артикул, цена) и **Склады**.
- Документ **ПоступлениеТоваров**: шапка со складом, табличная часть с товарами, количеством и ценой. При проведении создаёт движения прихода.
- Документ **РеализацияТоваров**: движения расхода. Перед проведением проверяет остатки по каждому товару с учётом суммы по документу и запрещает проведение при нехватке.
- Проверка заполнения документов: дата в диапазоне месяц назад — месяц вперёд, заполнен склад, есть товары, нет пустых строк.
- Регистр накопления **ТоварыНаСкладах** (вид «Остатки», измерения: номенклатура и склад, ресурс: количество).
- Общие модули:
  - **УправлениеОстатками** — `ПолучитьОстатки`: остатки списка товаров по складу одним запросом.
  - **УправлениеДвижениями** — `ЗаписатьДвиженияТоваров`: запись движений по строкам документа.
  - **ПроверкаДанныхДокументов** — функции проверки даты, склада, табличной части и пустых строк.
- Отчёт **ОстаткиТоваров** на основе схемы компоновки данных (СКД): остатки по номенклатуре и складу.
- Подсистема **СкладскойУчет**.

## Известные ограничения

- Сообщения об ошибках выводятся через `Сообщить`, без подсветки полей.
- Проверка цены и количества больше нуля ещё не реализована.
- Проверка дат при проведении задним числом по закрытым периодам не сделана.
